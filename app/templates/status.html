Run the ML forecasts

Forecasts page

The hybrid ARIMA + Ridge model is too heavy for Vercel, so it runs in GitHub Actions every Friday night (about 01:00 IST Saturday). It also refreshes the category averages. To run it now:

  1. Open the ML forecast workflow on GitHub (you need to be signed in with access to the repository).
  2. Click Run workflow on the right, keep the branch as main, and click the green Run workflow button.
  3. Wait 5–10 minutes. A new "ML forecasts" row appears in the job list above, and the Forecasts page shows the new ranges and accuracy.
