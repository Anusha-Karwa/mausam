    How to find a scheme code

    1. Easiest: type the fund's name in the search box. Mausam asks mfapi.in for you.
    2. Or search on mfapi.in. The number in each result is the scheme code.
    3. Or look the fund up on the AMFI website (the official mutual fund body). The code is listed next to each plan.
